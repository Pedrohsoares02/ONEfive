# Troca com o ChatGPT

Esta pasta é o ponto de encontro. Claude lê e escreve aqui direto, pela pasta
conectada do Mac — não é preciso colar nada no chat.

**Indo para lá:** anexe `briefing.md` na conversa do ChatGPT. Sem ele, o que
voltar vai ser bonito e estranho ao resto do painel.

**Voltando para cá:** salve a resposta como arquivo nesta pasta e diga
"salvei". Nome livre, de preferência dizendo o que é: `leads-opcao-a.html`,
`criticas-ponderacao.md`.

Nada aqui é código de produção. O que for aproveitado é reescrito e testado
antes de entrar no painel.
